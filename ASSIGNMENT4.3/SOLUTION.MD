## 1. Concepts used

| HTML element                  | Purpose                                            |
| ----------------------------- | -------------------------------------------------- |
| `<table>`                     | Creates the marksheet table                        |
| `<caption>`                   | Provides a title for the table                     |
| `<thead>`                     | Groups the column headings                         |
| `<tbody>`                     | Contains the student records                       |
| `<tfoot>`                     | Displays class totals and the overall average      |
| `<tr>`                        | Creates a table row                                |
| `<th>`                        | Defines a header cell                              |
| `<td>`                        | Displays a data cell                               |
| `colspan="3"`                 | Makes the Subject Marks heading span three columns |
| `rowspan="2"`                 | Makes selected headings span two rows              |
| `scope="col"` / `scope="row"` | Helps identify column and row headers accessibly   |
